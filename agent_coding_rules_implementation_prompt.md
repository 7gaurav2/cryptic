## 1. Non-Negotiable Coding Standards
1. **No Mock Processing:** Never use `setTimeout` to fake file compression, PDF manipulation, or encryption. Every tool **must** perform genuine binary manipulation using `window.crypto.subtle`, `HTMLCanvasElement`, `DataView`, and `pdf-lib` / `pdf.js`.
2. **Strict Aesthetic Adherence:**
   * Background MUST be Warm Stone (`#EAE6DF`) and Unbleached Vellum (`#F4F1EA`) with Matte Charcoal (`#232220`) hardware accents and Burnt Terracotta (`#C85A32`) primary triggers.
   * Zero neon gradients, zero purple/blue SaaS glows, zero pure `#000000` or `#FFFFFF` surfaces.
3. **3D Interactive Craftsmanship:**
   * The 3D Vault Core (`VaultCore3D`) must run smoothly at 60 FPS, respond to mouse coordinates, and visually react to application state (`idle`, `hovering-file`, `processing`, `complete`).
   * All tool cards must feature subtle 3D tilt physics and specular lighting on mouse move.
4. **Self-Contained Client Execution:**
   * Never make `fetch()` or `XMLHttpRequest` calls to external APIs for file processing.
   * Log every step of local binary transformation to the bottom status rail with millisecond timestamps so the user feels the transparency of the engine.
